# 实况照片解析边界

## D08b

- 缓存 key 由稳定媒体标识、URI、文件大小、修改时间和视频 offset/size 组成 SHA-256 摘要；文件名不直接暴露媒体路径，媒体版本变化会自然失效旧缓存
- 提取过程使用同目录 `.tmp` 文件，成功替换为最终文件；短文件、读取不足、异常和协程取消都会删除临时文件
- 精确 XMP offset 仍优先使用；无 offset 时只探测文件尾部最多 8MB，避免一次播放为超大照片分配 36MB byte array。超出可探测范围时返回现有中文回退提示，不把文件当成可播放结果
- 单元 fixture 覆盖合法 `ftyp` + `moov` 尾部和损坏 movie box；真实 OEM、HEIC/HEIF、超大文件、系统相册回退仍需设备媒体样本验证
