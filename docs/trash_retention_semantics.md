# 回收站复核语义

看了么的回收站不会因为项目存放达到某个天数而自动永久删除媒体。加入回收站时记录的时间用于生成一个本地“建议复核日期”，帮助用户定期检查内容。

当前建议复核窗口为 30 天：

- `TrashItemEntity.autoDeleteAt` 保留原数据库列名，以避免无意义的 Room schema 迁移；代码通过 `reviewDueAt` 访问它。
- `reviewDueAt` 只是提醒时间，不是后台删除任务的触发时间。
- 复核日期到达后，项目仍保留在回收站，用户可以恢复或主动发起永久删除。
- 永久删除仍必须经过 Android MediaStore 的系统授权流程，并以系统确认后的实际媒体状态为准。

实现和边界测试集中在 `TrashRetentionPolicy`，覆盖 30 天计算、临界日倒计时和已到期状态。
