- API 30：系统对话框显示 `Allow Keepix to access photos and media on your device?`；选择 `Allow` 后 `READ_EXTERNAL_STORAGE` 为 `granted=true`，应用进入空媒体首页。撤销并在对话框选择 `Deny` 后权限为 `granted=false`/`USER_FIXED`，应用回到 `Photo library access required` 授权页。

- API 36 denied：撤销三项媒体权限并选择 `Don’t allow` 后三项均为 false，应用保持授权页。以上 full/partial/denied 状态均来自 AVD 的 `dumpsys package` 与应用可见文案，不由单元测试推断。
