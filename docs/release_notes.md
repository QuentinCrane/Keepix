# 看了么 2.3.5

版本号：`2.3.5` · 版本代码：`61` · 支持 Android 11 及以上

## 进阶照片和视频筛选

- 新增照片筛选，可按文件夹、照片类型、分辨率、大小、格式、方向和时间查找，并在筛选结果中连续浏览。照片预览支持双击或双指缩放，长图可分块阅读。
- 完善视频筛选，支持按文件夹、分辨率、大小、时长、格式、方向和估算码率等条件查找；列表与网格可切换，播放时可查看上一条或下一条结果。
- 筛选结果可使用其他应用打开、选择目标文件夹移动或移入看了么回收站。移动受 Android 系统权限与存储卷限制，删除先进入应用回收站。

## 文件夹随机播放

- 通过系统文件夹选择器查找本地视频，可选择是否包含子文件夹。找到的视频按随机顺序循环播放，并可切换上一条或下一条。
- 关闭播放器后可重新播放当前列表；重新扫描会更新文件并重新打乱顺序。无法播放的视频会尝试跳过，全部连续失败时可重试。

## 播放与整理体验

- 播放器新增手动横竖屏切换；旋转时保留播放进度、播放状态、音量和倍速，退出播放器后恢复进入前的方向设置。
- 支持双击快进或快退、拖动定位、长按临时倍速，以及通过画面两侧调节播放器亮度和音量；更多菜单提供手势说明。
- 照片和视频筛选页增加已启用条件数量、搜索清除按钮和适配屏幕宽度的网格布局，整理、引导与预览交互也进行了优化。

## 使用说明

- 从 2.2.8～2.3.4 升级时，应用会迁移已有的收藏、回收站和整理记录；旧版统计原始记录也会保留。旧版本没有记录的统计细节无法补全。
- 如果极早版本的数据库不受支持，或旧库中存在无法安全合并的数据冲突，应用可能暂时无法打开；旧库不会被自动清空，请勿清除应用数据并联系维护者。
- 照片和视频筛选读取系统媒体库中已授权的项目；文件夹随机播放通过系统文件夹授权读取，不要求视频已被媒体库索引。
- 部分平板可能以兼容窗口显示横屏播放器；分屏或设备设置可能限制方向切换，播放器会在未响应时提示。
- 照片、视频和整理记录在本机处理，不上传到服务器。删除后的媒体可在应用回收站中查看和恢复；永久删除仍需经过系统确认。
