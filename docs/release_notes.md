# 看了么 2.3.4

版本号：`2.3.4`，版本代码：`60`

## 本版内容

- 继续保持本地优先，不需要账号、订阅或云同步
- 照片和视频支持连续整理、保留、收藏、删除与撤回
- 删除先进入看了么回收站，永久删除再经过 Android 系统确认
- 提供收藏、相似照片、当年今日、统计和设置等本机功能
- 手机和平板继续使用自适应布局

## 2026-08-18 更新

- 照片/视频滑动引导弹窗改为深色玻璃卡片风格，说明文字与按钮改为可本地化文案。
- 首次启动引导页改为固定深色渐变主题，矮屏自动使用紧凑间距与可滚动布局。
- 设置页“视频整理页实时预览”按容器宽度自适应高度，补齐深色操作栏与底部组件预览。
- 视频整理页顶部进度胶囊可跟随设置隐藏；顶部/底部渐变遮罩只在控制栏可见时叠加，减少对视频画面的遮挡。
- 已使用历史 release keystore 在本机签名构建 `app-release.apk`（v2 签名，证书 SHA-256 `ade29388…dbee`），签名与元数据记录见 `docs/发布候选验证记录_2026-08-14.md`。

## 隐私边界

照片、视频、整理记录和设置只在本机处理与保存，不上传到服务器。
