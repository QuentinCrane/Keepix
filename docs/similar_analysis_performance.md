# 相似照片分析性能合同

## D08a

- 指纹计算继续按 `PAGE_SIZE` 分页，每页完成后写入 Room、更新任务游标并检查取消/媒体版本；不把全库图片解码到内存
- 已缓存检查只读取 `photo_id` 投影，不再用 `allFingerprints()` 加载全部指纹实体来建立缓存 ID 集合
- 聚类阶段按最多 900 个 photo ID 分批查询指纹，避开 SQLite bind 参数上限；只保留当前分析照片、且含颜色统计的有效指纹
- 现有算法版本和任务游标仍是恢复边界；本块没有改变分组阈值、最佳照片选择或结果解释
- 当前没有连接设备，因此没有宣称照片/秒、峰值 PSS 或 precision 已改善；需要后续基准设备验证算法收益与内存曲线
