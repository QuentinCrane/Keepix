## 验收矩阵

| 场景 | 操作 | 通过标准 | 结果/证据 |
| --- | --- | --- | --- |
| 首次打开首页 | 在媒体总数仍增长时启动应用 | 不先显示“没有照片”；准备结束后首页自行重试并显示预览或准确空状态 | |
| 清理队列 | 固定随机种子，刷新/续接队列 | 同一范围和种子下当前卡片与顺序不漂移；自动化覆盖 Room 查询顺序 | |
| 那年今日 | 首页进入、系统返回、再次进入、选择“回到那天” | 入口不重复打开；返回回到原路径；月份/日期筛选语义正确 | |
| 视频静音 | 打开视频、切换静音、调整系统媒体音量、切页 | 图标与实际状态一致；切页不串音；离开页面后播放器释放 | |
| 照片滑动音效 | 保留/收藏/待删各执行一次，轮换三种音色 | 仅提交动作后播放；关闭设置后无声；系统静音和媒体音量遵守系统行为；页面离开后释放 | |
| 音效反馈 | 在支持的 API 设备安装 Release-like 包 | 三种平台反馈均可触发，无音量突变或崩溃；记录实际听测 | |
| 系统回收站授权 | 系统回收站模式下单项/批量待删，确认或取消系统对话框 | 取消时 Room 和媒体状态均不变；确认后先由系统处理，再同步 Room；批量按安全批次继续 | AndroidTest 可编译；尚未有设备执行系统授权对话框 |
| 系统回收站恢复 | 回收站单项/批量恢复，包含应用待删和系统 trashed 项目 | 应用待删直接本地恢复；系统 trashed 先弹系统授权；取消不删除本地项目，确认后才从 Room 恢复 | AndroidTest 可编译；尚未有设备执行系统授权对话框 |
| 文件夹移动/归档 | 查看器移动、整理页指定归档、启用自动移动后确认保留/收藏 | 先显示系统写入授权；取消不改变队列和 Room；确认后 MediaStore 成功才同步文件夹字段；后续动作失败尝试恢复原目录 | AndroidTest 可编译；尚未有设备执行系统授权对话框 |
