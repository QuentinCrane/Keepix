# 本地数据保留策略

## D05d

| 数据 | 策略 | 原因 |
| --- | --- | --- |
| `operation_history` 已撤销记录 | 保留 90 天；写入新操作时清理 cutoff 之前的 `is_undone = 1` 行 | 不影响当前撤销；避免历史无限增长 |
| `operation_history` 未撤销记录 | 不自动删除 | 保留可用撤销语义，避免后台清理改变用户可撤销操作 |
| `photo_fingerprints` | 相似分析开始时删除不再属于 active candidate 的指纹 | 避免已删除、缺失、RAW/GIF 或无尺寸媒体的缓存长期占用空间 |
| `missing_since` 媒体行 | 暂不自动删除 | 保留稳定 ID、恢复/审计和后续重新出现的媒体关联 |
| `cleanup_events` | 永久保留本地账本 | 年度报告、成就和统计依赖历史事件 |
| 相似分组/任务 | 成功替换分组；任务保持单例 | 结果可解释且可恢复，不产生无界任务行 |

该策略不涉及永久删除用户媒体，也不改变应用回收站的保留提示语义。
