# 照片整理视觉与模式决策

C04 保留 `immersiveBackground` 和 `photoCleanMode`，但让每个值都有整理页上的真实结果。DataStore key 保持不变，旧版本设置继续读取；本块不改变照片队列、滑动动作、撤销记录或删除授权语义。

| 设置 | 值 | 整理页可观察结果 | 队列/手势/撤销影响 |
| --- | --- | --- | --- |
| 沉浸背景 | 开 | 当前照片作为模糊背景，保留渐变遮罩和入场动效 | 无 |
| 沉浸背景 | 关 | 只显示黑色基础层与必要遮罩，不请求背景图解码 | 无 |
| 照片清理模式 | 正常使用 | 按沉浸背景开关显示完整视觉效果，预取 3 张预览图 | 无 |
| 照片清理模式 | 帮助排查 | 保留正常视觉，并在顶部显示预览队列、当前媒体、剩余数和进度诊断条 | 无 |
| 照片清理模式 | 流畅优先 | 强制关闭模糊背景和入场动效，预取窗口降为 1 张 | 无；保留、收藏、待删、撤销和统计路径不变 |

## 验收

- 修改沉浸背景后重新进入照片整理页，背景图层出现或消失，照片卡片和手势不变
- 三种清理模式分别显示上述结果；性能模式不再创建沉浸背景图层
- 诊断模式不改变动作回调、随机种子、撤销栈或删除授权
- 进程重启后仍由原 DataStore key 恢复设置；旧值不存在时仍使用原来的 `true` / `NORMAL` 默认值
